Функции мышки
Вращение колеса мыши вниз изменит увеличит масштаб изображения. Вращение колеса вверх изменяет уменьшит масштаб изображения.
ННажатие на прокрутку устанавливает камеру за/перед вами. Полезно если приходится убегать отстреливаясь.
Прокруткой так же управляют кнопки Page Up/Page Down.
